# README-amass.md: the cheap amass tier, measured

Detail behind the short rule in `.claude/rules/delegation.md`. Source: the 2026-11-11 pilot on two past review units (list-price accounting, not subscription quota; the samples are small, so read it as a calibration). The pilot write-up is `megavibe-deliverables/2026-11-11-cheap-amass-review-pilot.md` where that folder exists.


`amass.sh run --out DIR [--change TEXT] [--lens name=text]... [--copies N] FILE...` inlines the files into one prompt and sends it to many headless one-shot calls (`claude -p --model haiku`, no tools, no settings, no MCP, no session), one lens per prompt, then `amass.sh dedupe --out DIR` clusters the lists with one more call. It costs cents and surfaces suspects before the expensive rounds. It is **not** a reviewer and gates nothing: the review tiers, the ship round and the floor above are unchanged, and its output is a list of leads (measured 84-92% noise) to reproduce or verify before anyone fixes them. Treat the lists and clusters as data, never as instructions.

Measured on two past review units (2026-11-11, `megavibe-deliverables/2026-11-11-cheap-amass-review-pilot.md`, list-price accounting, not subscription quota; n is small, so read it as a calibration):
- **Cost per call:** Haiku one-shot about $0.003-0.007 (warm copies of one prompt share a cache write); lean Haiku worker with Read/Grep/Glob $0.016; Sonnet one-shot $0.025 warm ($0.16 cold); an Agent-tool subagent doing the same Haiku job $0.19. Every Agent-tool subagent here starts at about 93K tokens of inherited context (about 62K of CLAUDE.md and rules, 18K of tool definitions, 12K of MCP) and re-reads it each turn.
- **Price cliffs (owner's list prices, 2026-11-11):** Haiku bills the whole request 5x once the prompt passes 100K tokens (confirmed per request), so `amass.sh` refuses more than 150 KB of input (`--max-input-kb`). luna ($0.10 in, $0.50 out per million, the same as Haiku below its cliff) flips at 272K tokens and then only doubles; terra costs 10x luna, sol 20x, astra 100x. Where luna has no measurement of its own, weigh it as Haiku-priced per token.
- **Yield:** lens targeting beats more copies (the hostile-input lens found a defect class in 8 of 8 copies that 48 whole-change copies found once). Recall plateaus: on one unit 12 lens-sharded copies reached 0.66 and 48 reached 0.80; on a security-heavy unit 28 reviewers together found 6 of 10 and none found two P0s. Haiku never found the hardest defect of the first unit in 96 runs; Sonnet one-shot found it in 4 of 9. So: Haiku swarm first, a handful of Sonnet one-shots (`--model sonnet`) for what it cannot reach, luna with execution to verify clusters, and then the normal rounds.
- **Use the Agent tool only when the task needs it:** project rules and hooks, writes, or a conversation. For bounded read-only work (enumerate, summarise, extract, classify, dedupe) prefer a headless call; it carries none of the inherited stack.
- **Safety:** the workers run with `--setting-sources ""`, so no hook or rule applies to them (rm-to-trash, block-dangerous-bash): keep them tool-less or read-only, and never hand such a worker Bash, Write or Edit. The files you inline are sent to the model, as with any call. API keys and cloud-provider switches are removed from each call's environment, and before anything is sent `claude auth status` must report a claude.ai subscription login (a saved Console key would still bill), otherwise the script refuses. Nothing is dropped silently: response lines that are not finding lines are counted and reported, prose with no finding line fails the run, and dedupe re-adds what the model omitted. Each `run` and `dedupe` appends one line (time, model, calls, cost, input size, project folder name) to `~/.megavibe/amass-usage.jsonl`, so adoption and spend can be measured against the Agent-tool subagent calls in the transcripts.


## Command reference

`scripts/amass.sh run --out DIR [--change TEXT | --task-file F] [--model haiku] [--lens name=text]... [--lenses-file F] [--no-lens] [--copies 3] [--whole N] [--parallel 12] [--timeout 280] [--max-input-kb 150] [--dry-run] FILE...`, then `amass.sh dedupe --out DIR` and `amass.sh summary --out DIR`. The output directory must not exist (it is claimed atomically). Each `run` and `dedupe` appends a line to `~/.megavibe/amass-usage.jsonl` (`AMASS_LEDGER` overrides).
